# Checkrally

**Think ahead. Break their reach. Checkmate the rally.**

Checkrally is a turn-based tennis puzzle game about creating a court position your opponent can no longer defend.

This repository is the Godot 4.6 prototype. The current development target is **v0.8 Core Puzzle Rebuild**, designed as a compact grant-demo slice for the Draknek New Voices Puzzle Grant 2026.

## Core idea

- No reflexes, timing, or aiming.
- Choose a shot and its landing square.
- Read the opponent's visible **Reach**.
- If the opponent reaches the ball, their position and stance change.
- Use Drop, Lob, Cross, and Drive to reshape what they can defend.
- Land outside Reach to win the rally.

The puzzle is not about hitting harder. It is about making the next ball impossible to reach.
